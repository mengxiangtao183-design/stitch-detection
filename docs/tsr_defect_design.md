# TSR-Defect：轨迹自参照缺陷检测单元

## 与论文 SPMM 的区别

TSR-Defect 不做针距测量、像素到毫米转换、连通域质心定位、面积筛选或宽度连接约束。它也不依赖显微镜标定。输入仅为 C3Net 的 `final_mask` 概率图，输出为每张图六个线迹单元的可解释缺陷候选。

## 核心思想

同一张图中六段线迹互为“正常参考”。检测器以每一列的概率加权 y 重心构造一条软轨迹，拟合并移除图像整体斜率，然后将当前单元与其余五段的稳健中位数比较。故纹理、拍摄位置和整体轻微倾斜不直接决定缺陷。

| 类型 | 新的主要证据 |
|---|---|
| 跳线 | 局部轨迹支撑突然消失、形成内部横向缺口，随后恢复 |
| 断线 | 当前有效轨迹跨度显著短于同图其余单元，并伴随缺口 |
| 歪斜 | 当前标签为整条线迹的整体歪斜，且已排除拍摄角度；故以整条轨迹相对水平的连续全局斜率分数判别 |
| 松线 | 去趋势后的曲线偏离、弧长增量与弯折能量异常；兼容 U、S、局部折弯，不要求中点下垂 |

每段同时保留 `coverage`、`gap_ratio`、`span_ratio`、`arc_ratio`、`deviation_px`、`sag_px`、`bend_energy`、`local_slope`，以便审计每个判定。

## 使用边界

规则阈值是初始运行阈值，不应使用测试集调参。应在每折训练来源中留出的验证图上校准阈值；若该类正图不足，则保持默认阈值并报告样本不足。首尾因拍摄裁切不完整的单元必须在标签中保持 `valid=0`。

当前数据的歪斜标签已排除拍摄角度，因此默认开启 `enable_global_skew`。该分数不再使用会快速饱和的固定阶梯，而是保留连续斜率供每折校准阈值。若未来采集端姿态不可控，应关闭此开关。

当前 `skew` 标签将整图六段一并标注，故默认关闭 `enable_local_skew`，避免把正常针迹的局部波纹误报为歪斜。若日后单独标注局部歪斜单元，再启用它。
