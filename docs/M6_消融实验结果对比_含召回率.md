## 实验协议

- 训练协议：Full150，随机种子 42。
- 训练/验证数据：DB、XJ、SD；RX 仅作为外部泛化测试集。
- 表中精度指标为 DB、XJ、SD、RX 四个数据集的宏平均，单位均为 `%`。
- 单张推理时间采用 batch size = 1 的统一测试结果。
- “提升”均表示绝对百分点变化，而非相对百分比。

## 结果分析（论文可用）

消融结果表明，三个改进阶段具有连续的正向累积效果。首先，LMFR 将四数据集宏平均 Binary IoU 和 Binary Recall 分别提高 0.652 和 1.051 个百分点，同时将单张推理时间由 53.55 ms 降至 15.19 ms，说明轻量编码与跨尺度重建在显著提高推理效率的同时增强了线迹像素检出能力。随后加入 HSR 后，Binary IoU、Binary F1 和 Boundary F1@1px 进一步提高 0.810、0.473 和 0.208 个百分点，表明高分辨率细化有助于恢复细窄线迹区域并改善边界质量。最后加入 APG-HR 后，Binary Recall 再提高 0.950 个百分点，最终 M6 相对原始 C3Net 的 Binary IoU、Binary F1、Binary Recall 和 Boundary F1@1px 分别提高 1.610、0.934、3.035 和 0.389 个百分点。

从不同数据集的 Recall 结果看，M6 在 DB、XJ、SD 和 RX 上均取得提升，其中外部测试集 RX 的增幅最大，达到 4.133 个百分点。这说明最终网络的主要优势是减少细线迹和弱线迹的漏检，并且该能力能够迁移到未参与训练的外部纹理场景。与此同时，M6 的 Precision 相对原始 C3Net 下降 1.213 个百分点，说明召回提升伴随一定的假阳性增加；但 IoU、Binary F1 与 Boundary F1 均同步提高，表明总体区域重叠与边界质量仍获得净提升。

在效率方面，M6 的单张推理时间为 16.47 ms，相比原始 C3Net 减少 37.08 ms，约降低 69.2%，对应理论处理速度约为 60.7 FPS，仍满足实时检测需求。
