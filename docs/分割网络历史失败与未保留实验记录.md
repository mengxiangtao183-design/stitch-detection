# 分割网络历史失败与未保留实验记录

本文档记录M6形成前后的结构尝试、改进方法和未保留原因。这里的“未保留”包括明确掉点、收益不能稳定复现、只在快速协议中微涨但全量失败，以及与最终结构功能重复的版本。

2026-08-26已按用户确认删除87个失败/未保留实验的YAML配置；训练权重、评估结果、预测图和网络实现代码均保留。精确文件清单见`docs/已删除失败配置清单.md`。

## 6. 最终保留关系

正式主线建议只保留：原始C3Net Baseline、M0 MobileNetV4+LMFR、M4 HighRes、M6 AFM-guided HighRes，以及它们对应的Full150、计时和必要诊断配置。E1作为LMFR拆分验证可保留；D1和M25/M26仅作为历史诊断证据，不应混入M6论文主结构。

## 7. 共同失败规律

1. 织物周期纹理与线迹本身都具有局部重复性，纯纹理抑制很容易误伤前景。
2. 在P2/P3反复增加对齐、重采样和残差细化，会把浅层纹理噪声重新注入定位路径。
3. 只提高Precision的抑制模块通常降低Recall；只补前景的模块又容易扩大假阳性。
4. Clear100上的0.1—0.3点微涨无法稳定外推到Full150，D1和M26均已证实这一点。
5. M6后继续堆叠头部或门控模块，与HighRes/APG-HR功能重复，收益趋近饱和。
